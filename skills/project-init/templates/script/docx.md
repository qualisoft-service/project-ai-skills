# 산출물 생성 지시 — 워드 (DOCX)

`__PROJECT__` 프로젝트의 **`__DOC_TITLE__`** 을 고객 송부용 워드로 만들어 주세요.

읽을 수 없으면 만들지 말고 파일을 달라고 요청하세요.

## 워드 구성

1. **첫 쪽에 목적 블록.** 제목 22pt 굵게 → 답하는 질문 → 핵심 수치를 1행 표로
   가로 나열(테두리 없이, 숫자 24pt 굵게 + 이름표 9pt) → 받는 분이 할 일.
   그 뒤 쪽 나누기.
2. **머리글 스타일(제목 1/2/3)을 실제로 적용**해서 탐색 창과 목차가 동작하게
   합니다. 글자 크기만 키우지 마세요.
3. 본문 10pt, 줄간격 1.5, 문단 뒤 6pt.
4. 표는 `Table Grid` 기반에 공통 규격 음영. 머리행 반복 속성을 켜세요.
5. 한글 서체를 **동아시아 글꼴 속성에도 함께 지정**합니다. 빠뜨리면 한글만 다른
   서체로 보입니다.
6. 목차는 넣지 않습니다. 필요하면 따로 요청합니다.

만든 뒤 적용한 머리글 수준별 개수를 알려주세요.
