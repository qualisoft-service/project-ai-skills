# 산출물 생성 지시 — 워드 (DOCX)

`__PROJECT__` 프로젝트의 문서 **`__DOC_TITLE__`** 을 워드 산출물로 만들어 주세요.

## 원본

`__DOC_FILE__` — **이 파일을 먼저 읽고**, 그 내용만으로 만듭니다.
읽을 수 없으면 만들지 말고 파일을 달라고 요청하세요.

## 결과물

- 파일명: `__DOC_STEM__.docx`
- A4 세로, 위아래 여백 2.2cm, 좌우 2.4cm

__STYLE__

## 워드 고유 규칙

1. 본문 기본 10pt, 줄간격 1.5, 문단 뒤 간격 6pt.
2. 제목 22pt 굵게 → 바로 아래 메타 한 줄 9pt 보조색 → 빈 줄.
3. `##` 15pt 굵게(앞 간격 16pt), `###` 12pt 굵게, `####` 10.5pt 보조색.
4. **머리글 스타일(Heading 1/2/3)을 실제로 적용**해서 목차와 탐색 창이 동작하게
   합니다. 글자 크기만 키우지 마세요.
5. 목록은 워드 글머리 기호 스타일을 씁니다.
6. 표는 `Table Grid` 기반에 공통 규격의 음영을 입힙니다. 표 뒤에 빈 문단 하나.
7. 인용(`>`)은 왼쪽 들여쓰기 0.6cm + 보조 글자색.
8. 한글 서체를 **동아시아 글꼴 속성에도 함께 지정**합니다. 이걸 빠뜨리면 한글만
   다른 서체로 보입니다.

## 지켜야 할 것

- **원본의 문장을 바꾸지 마세요.** 서식만 입힙니다.
- 원본의 `TODO(...)` 는 그대로 남깁니다.
- 표지·목차 페이지를 임의로 추가하지 마세요. 필요하면 따로 요청합니다.
- 다 만든 뒤, 적용한 머리글 수준별 개수를 알려주세요.
