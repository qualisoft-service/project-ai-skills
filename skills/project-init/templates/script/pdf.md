# 산출물 생성 지시 — PDF

`__PROJECT__` 프로젝트의 문서 **`__DOC_TITLE__`** 을 PDF 산출물로 만들어 주세요.

## 원본

`__DOC_FILE__` — **이 파일을 먼저 읽고**, 그 내용만으로 만듭니다.
읽을 수 없으면 만들지 말고 파일을 달라고 요청하세요.

## 결과물

- 파일명: `__DOC_STEM__.pdf`
- 용지 A4 세로, 바깥 여백 20mm

__STYLE__

## PDF 고유 규칙

1. **표지 없이 본문부터** 시작합니다. 첫 줄이 문서 제목입니다.
2. 제목 바로 아래 한 줄로 메타를 넣습니다 — `문서ID · 상태 · 담당 · 수정일`,
   보조 글자색 9pt.
3. 모든 쪽 상단에 머리말: 왼쪽에 문서 제목, 오른쪽에 문서 ID, 그 아래 얇은 구분선.
4. 모든 쪽 하단 가운데에 쪽번호.
5. 절 제목(`##`)은 앞에 새 쪽을 강제하지 않습니다. 다만 **제목만 남고 내용이 다음
   쪽으로 넘어가는 일은 없게** 합니다.
6. 인용(`>`)은 왼쪽에 강조색 세로 막대를 두고 보조 글자색으로 씁니다.
7. 코드 블록은 `#FAFAF8` 배경에 고정폭, 줄바꿈하지 말고 넘치면 줄여 씁니다.
8. 표가 한 쪽에 안 들어가면 머리행을 반복하며 나눕니다.

## 지켜야 할 것

- **원본의 문장을 바꾸지 마세요.** 서식만 입힙니다. 요약·윤색·보완 금지.
- 원본에 `TODO(...)` 가 있으면 **그대로 남깁니다.** 채우지 마세요.
- 표의 행 순서와 칸 수를 바꾸지 마세요.
- 다 만든 뒤, 원본의 절 제목이 모두 들어갔는지 세어서 알려주세요.
