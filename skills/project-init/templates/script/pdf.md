## PDF 구성

1. **1쪽은 목적 쪽입니다.** 제목, 답하는 질문, 핵심 수치, 받는 분이 할 일.
   수치는 가로로 나란히 놓고 숫자 28pt 굵게, 이름표 9pt 보조색.
   이 쪽에 본문을 섞지 마세요.
2. **2쪽부터 본문.** 가장 중요한 표가 먼저 옵니다.
3. 모든 쪽 상단에 머리말 — 왼쪽 문서 제목, 오른쪽 프로젝트명, 아래 얇은 구분선.
   **문서 ID 를 머리말에 넣지 마세요** (내부 표기입니다).
4. 모든 쪽 하단 가운데 `n / 전체` 쪽번호.
5. 절 제목만 남고 내용이 다음 쪽으로 넘어가지 않게 합니다.
6. 표가 한 쪽에 안 들어가면 **머리행을 반복하며** 나눕니다.
7. 인용은 왼쪽에 강조색 세로 막대 + 보조 글자색. 단, `_scope.md` 에서 걸러내라고
   한 작성 지침 인용문은 아예 빼세요.

## 한글 폰트
