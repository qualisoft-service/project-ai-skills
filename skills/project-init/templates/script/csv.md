# 산출물 생성 지시 — CSV

`__PROJECT__` 프로젝트의 **`__DOC_TITLE__`** 을 CSV 로 만들어 주세요.

CSV 는 **데이터를 넘기는 형식**입니다. 목적 설명이나 서식이 들어가지 않으므로,
고객이 표를 바로 쓸 수 있게 만드는 것에 집중합니다.

## 원본

`__DOC_FILE__` — **이 파일을 먼저 읽고**, 그 내용만으로 만듭니다.

## 결과물

원본의 표를 하나씩 파일로 떨어뜨립니다. **파일명은 내용을 말하게** 지으세요 —
`__DOC_STEM___구축범위.csv` 처럼. `표1.csv` 같은 이름은 쓰지 마세요.

본문 설명은 CSV 로 만들지 않습니다. 설명이 필요하면 PDF·엑셀을 쓰세요.

__SCOPE__

## 인코딩 — 이것만은 반드시

**UTF-8 with BOM(`utf-8-sig`) 으로 저장합니다.** BOM 이 없으면 엑셀에서 열 때
한글이 깨집니다. CSV 산출물에서 가장 자주 나는 사고입니다.

줄바꿈은 `\r\n`. 값에 쉼표·따옴표·줄바꿈이 있으면 큰따옴표로 감싸고 내부 따옴표는
두 번 씁니다 (표준 CSV 규칙).

## 표 형식

- 머리행이 **비어 있거나 중복되면 이름을 붙여 고칩니다** (`항목`, `구분 2`)
- 행 순서를 바꾸지 마세요. 원본 순서가 곧 의미입니다
- 칸 수가 행마다 다르면 가장 넓은 행에 맞춰 빈 칸으로 채웁니다
- 마크다운 기호(`**`, 백틱, `[[링크]]`)는 벗겨내고 글자만 남깁니다

만든 뒤 파일 목록과 각 파일의 행 수를 알려주세요.
