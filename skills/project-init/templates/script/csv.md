# 산출물 생성 지시 — CSV

`__PROJECT__` 프로젝트의 문서 **`__DOC_TITLE__`** 을 CSV 로 만들어 주세요.

## 원본

`__DOC_FILE__` — **이 파일을 먼저 읽고**, 그 내용만으로 만듭니다.
읽을 수 없으면 만들지 말고 파일을 달라고 요청하세요.

## 결과물

파일 여러 개로 나눕니다.

| 파일 | 내용 |
| --- | --- |
| `__DOC_STEM___개요.csv` | 본문 전체를 구조화한 것 |
| `__DOC_STEM___표1.csv`, `표2.csv` … | 원본의 표를 순서대로 하나씩 |

## 인코딩 — 이것만은 반드시

**UTF-8 with BOM(`utf-8-sig`) 으로 저장합니다.** BOM 이 없으면 엑셀에서 열 때
한글이 깨집니다. 이 한 가지가 CSV 산출물에서 가장 자주 나는 사고입니다.

줄바꿈은 `\r\n`, 값에 쉼표·따옴표·줄바꿈이 있으면 큰따옴표로 감싸고 내부
따옴표는 두 번 씁니다 (표준 CSV 규칙).

## 개요 CSV 형식

머리행은 `구분,섹션,하위,내용` 네 칸 고정입니다.

| 구분 | 언제 |
| --- | --- |
| `본문` | 문단·인용 |
| `목록` | 불릿 항목 하나당 한 줄 |
| `코드` | 코드 블록. 줄바꿈은 ` ⏎ ` 로 바꿔 한 줄에 |

`섹션` 은 가장 가까운 `##`, `하위` 는 가장 가까운 `###`/`####` 입니다.

## 표 CSV 형식

- 원본 표의 **머리행과 행 순서를 그대로** 옮깁니다
- 칸 수가 행마다 다르면 가장 넓은 행에 맞춰 빈 칸으로 채웁니다
- 마크다운 기호(`**`, 백틱, `[[링크]]`)는 벗겨내고 글자만 남깁니다

## 지켜야 할 것

- 값을 정렬하거나 합치지 마세요. 원본 순서가 곧 의미입니다.
- 원본의 `TODO(...)` 는 그대로 남깁니다.
- 다 만든 뒤, 만든 파일 목록과 각 파일의 행 수를 알려주세요.
