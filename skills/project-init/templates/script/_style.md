## 산출물 공통 서식 규격

**이 규격은 고정입니다.** 프로젝트 초기에 만들든 중간에 만들든, 누가 어떤 도구로
만들든 **같은 값을 써서 같은 모양이 나와야 합니다.** 아래 값을 임의로 바꾸지 마세요.

### 색

| 쓰임 | 값 |
| --- | --- |
| 본문 글자 | `#1C1B19` |
| 보조 글자 (메타·주석) | `#6B6862` |
| 선·테두리 | `#E4E2DD` |
| 강조 (제목 앞 막대, 링크) | `#2383E2` |
| 표 짝수행·코드 배경 | `#FAFAF8` |
| 표 머리행 배경 | `#1C1B19` (글자는 흰색) |

**색은 이 여섯 개가 전부입니다.** 경고나 상태 표시가 꼭 필요하면 `#C0392B`(위험),
`#0F7B6C`(완료) 두 개만 더 씁니다.

### 글자

- 한글 본문은 산세리프: `맑은 고딕` → `Apple SD Gothic Neo` → 시스템 기본 순서로 대체
- 코드·경로·ID 는 고정폭
- 크기 위계는 **네 단계만**: 제목 / 절 제목 / 소제목 / 본문
- 본문 줄간격은 1.5~1.65. 빽빽하게 붙이지 않습니다

### 표

- 머리행은 먹 배경에 흰 글자, 굵게
- 짝수 데이터행에 `#FAFAF8` 음영 (얼룩무늬)
- 테두리는 가로선 위주로 얇게. 격자를 꽉 채우지 않습니다
- 셀 안쪽 여백을 넉넉히 (상하 6pt 이상)
- 머리행은 페이지·슬라이드가 넘어가도 반복

### 여백

- 바깥 여백을 넉넉히 둡니다. 가장자리까지 채우지 않습니다
- 절과 절 사이는 본문 간격의 두 배 이상

### 하지 말 것

- 무지개색·그라디언트·네온
- 그림자, 3D, 워드아트, 반사 효과
- 장식용 아이콘·클립아트·이모지
- 본문 기울임체 (한글에서 읽기 나쁩니다)
- 가운데 정렬 본문 (제목만 필요하면 씁니다)
- 원본에 없는 내용을 지어내기
