## 차트 시트 — 눈으로 보이는 것을 하나는 넣으세요

표만 있는 산출물은 **읽어야** 알 수 있습니다. 고객이 **보고** 알 수 있는 시트를
하나 이상 넣습니다. 문서에 쓸 내용이 있으면 그것으로 만들고, **없으면 `(예시)` 로
표시해 폼만이라도 보여주세요.** 빈칸으로 두지 않습니다.

### 무엇을 차트로 만드는가

| 문서에 이런 내용이 있으면 | 이런 시트를 만듭니다 |
| --- | --- |
| 기간·일정·단계·마일스톤 | **간트** (아래 규격) |
| 건수·구성비·분포 (부서별·등급별·상태별) | **가로 막대** |
| 공정·단계별 진행률 | **진행바** |
| 두 축의 관계 (요구사항↔과업, 역할×기능) | **매트릭스** |
| 선후 흐름·단계 전이 | **흐름 띠** |

문서 종류별 기본값입니다.

| 문서 | 차트 시트 |
| --- | --- |
| 로드맵 · WBS · 일정 | 간트 |
| 산출물 정의서 | 공정별 진행바 + 필수/선택 막대 |
| 요구사항 정의서 | 부서별 막대 + 타당성 막대 |
| 권한 정의서 | 역할 × 기능 매트릭스 |
| 리스크 대장 | 등급별 막대 (Blocker 는 위험색) |
| QA · 테스트 | 단계별 진행바 + 고객/수행사 비중 막대 |
| 화면 설계서 · 메뉴 구조 | 구분별 화면 수 막대 |
| 업무 개선 분석 | 현행 대비 개선 흐름 띠 |
| 그 밖 | 표의 **분류 열로 건수를 세어** 가로 막대 |

### 막대는 셀 배경색으로 칠합니다

엑셀 기본 차트를 쓰지 마세요. **셀을 칠하는 방식이 기본입니다.** 인쇄·PDF 변환에서
깨지지 않고, 차트 XML 손상으로 파일이 복구되는 일도 없습니다. 기본 차트를 덧붙이고
싶으면 **표를 반드시 함께 남긴** 뒤에 추가하세요.

### 간트 시트 규격

```
B      C                      D      E      F     G H I J K … (주차)
       간트 차트                                   ← 제목
       막대는 예시입니다. 합의된 일정이 아닙니다.    ← 전제 문구

ID     마일스톤                시작   종료   기간   1 2 3 4 5 6 7 8 …
MS-01  범위·전제 확정          W1     W3     3주    ███
MS-02  시안 제작 및 합의       W2     W5     4주    ░███░░░░░░░░
MS-03  설계 — 데이터·API       W4     W8     5주    ░░░█████░░░░
MS-08  일정 현실화 (미해소)    W1     W2     2주    ▓▓░░░░░░░░░░

보는 법
  ███  진행 구간 — 해당 주차에 이 항목이 진행됩니다
  ▓▓▓  미해소 — 이 결정에 따라 위 배분이 전부 바뀝니다
```

| 항목 | 값 |
| --- | --- |
| 좌측 고정 열 | `ID` · `항목` · `시작` · `종료` · `기간` |
| 주차 헤더 | `1` `2` `3` … 숫자만. 날짜가 확정이면 `9/15` 처럼 날짜로 |
| 막대 (진행) | `#1C1B19` 채움 |
| 막대 (위험·미해소) | `#C0392B` 채움 |
| 배경 트랙 | `#FAFAF8` — 막대가 없는 주차도 옅게 칠해 길이를 보이게 합니다 |
| 열 폭 | A `3` · ID `12` · 항목 `30` · 시작·종료·기간 각 `10` · 주차 `3.2` |
| 칸 안 글자 | **없음.** 색만으로 표현합니다 |
| 4주마다 | 세로 구분선을 넣어 달 경계를 보이게 합니다 |

### 날짜가 없으면 주차로 씁니다

착수일이 정해지지 않은 프로젝트가 많습니다. 그럴 때 **날짜를 지어내지 말고**
`W1`, `W2` 처럼 상대 주차로 적고, 시트 아래 주석에 그 이유를 한 줄 남깁니다.

> 착수일이 정해진 적이 없어 날짜 대신 상대 주차로 표시했습니다.

### 범례와 주석은 필수입니다

표 아래 한 줄 띄우고 **`보는 법`** 을 둡니다. 색 견본 칸을 실제로 칠하고 그 옆에
뜻을 적습니다. 색만 칠해 두면 받는 사람이 무슨 색인지 묻습니다.

그 아래 **주석** 으로 근거를 남깁니다 — 원본에서 무엇을 근거로 삼았는지, 무엇이
비어 있어 추정했는지, 어떤 결정에 따라 바뀔 수 있는지.

### 내용이 없을 때 — `(예시)` 로 만듭니다

문서에 일정·건수가 전혀 없어도 시트를 만듭니다. 다만 **속이지 않습니다.**

1. 시트 이름과 제목에 `(예시)` 를 붙입니다 — `간트 (예시)`
2. 제목 바로 아래 전제 문구를 굵게 둡니다
   > **막대는 예시입니다. 합의된 일정이 아닙니다.**
3. 행은 **원본에 있는 항목 이름으로** 채웁니다. 항목 이름까지 지어내지 마세요.
   원본에 항목이 없으면 그 문서의 절 제목을 항목으로 씁니다
4. 기간은 균등하게 배분하고, 주석에 "협의 전 균등 배분" 이라고 적습니다
5. 미정 항목은 위험색(`#C0392B`)으로 칠해 **눈에 걸리게** 둡니다

이렇게 하면 고객이 폼을 보고 "여기에 우리 일정을 넣으면 되겠다" 를 압니다.
빈 시트는 아무 말도 하지 않습니다.
