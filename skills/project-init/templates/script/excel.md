# 산출물 생성 지시 — 엑셀 (XLSX)

`__PROJECT__` 프로젝트의 문서 **`__DOC_TITLE__`** 을 엑셀 산출물로 만들어 주세요.

## 원본

`__DOC_FILE__` — **이 파일을 먼저 읽고**, 그 내용만으로 만듭니다.
읽을 수 없으면 만들지 말고 파일을 달라고 요청하세요.

## 결과물

- 파일명: `__DOC_STEM__.xlsx`

__STYLE__

## 시트 구성 규칙

1. **첫 시트 `문서`** — 본문이 위에서 아래로 흐릅니다.
   - A열은 폭 3(여백용), B열은 폭 110에 내용을 담고 자동 줄바꿈
   - 제목 20pt 굵게 → 메타 한 줄 9pt 보조색 → 빈 줄 → 본문
   - `##` 14pt 굵게, `###` 12pt 굵게, `####` 11pt 보조색
   - 목록은 `•` 를 붙이고 한 칸 들여쓰기
2. **표는 각각 별도 시트** (`표1`, `표2`, …) 로 뺍니다.
   `문서` 시트의 그 자리에는 `→ 표1 시트 참조` 라고 강조색으로 적습니다.
3. 표 시트마다:
   - 엑셀 **표 기능(Ctrl+T)** 을 적용해 정렬·필터가 켜지게 합니다
   - 머리행 고정(틀 고정 A2)
   - 열 너비는 내용에 맞춰 12~52 사이로
   - 얼룩무늬 켜기
4. **모든 시트에서 눈금선을 끕니다.**
5. 수식을 넣지 않습니다. 값만 씁니다.

## 지켜야 할 것

- **표의 행 순서·칸 수·값을 바꾸지 마세요.** 정렬하거나 합치지 마세요.
- 빈 칸을 임의로 채우지 마세요. 원본이 비어 있으면 비워 둡니다.
- 원본의 `TODO(...)` 는 그대로 남깁니다.
- 다 만든 뒤, 시트 수와 각 표의 행 수를 알려주세요.
