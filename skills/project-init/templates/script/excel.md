## 시트 구성

1. **첫 시트 `요약`** — 목적 블록이 여기 들어갑니다.
   - B2 에 문서 제목 20pt 굵게
   - 그 아래 답하는 질문 한 줄 11pt
   - 그 아래 핵심 수치를 **가로로 나열**: 각 칸에 숫자 24pt 굵게, 그 아래 이름표
     9pt 보조색. 칸 사이는 빈 열로 띄웁니다
   - 맨 아래 "받는 분이 할 일" 한 줄
2. **그 다음 시트부터 본표** — 시트 이름은 내용을 말하게 짓습니다.
   `표1` `표2` 같은 이름을 쓰지 마세요. `구축범위`, `마일스톤`, `요구사항` 처럼.
3. 시트가 다섯 개를 넘으면 성격이 가까운 표를 합치세요.
4. **모든 시트에서 눈금선을 끕니다.** 틀 고정은 머리행 아래(A2).
5. 수식을 넣지 않습니다. 값만 씁니다.

## 표를 만들 때 — 파일 손상을 막는 규칙

엑셀 **표 기능**(정렬·필터가 붙는 그것)을 쓸 때, 아래를 어기면 엑셀이 파일을 열며
**"파일에 오류가 있습니다 — 복구했습니다"** 를 띄웁니다. 마크다운 표를 그대로
옮기면 자주 걸립니다.

| 규칙 | 안 지키면 |
| --- | --- |
| 머리행 셀이 **비어 있으면 안 됩니다** | 복구 발생. `항목`, `구분`, `값` 처럼 채우세요 |
| 머리행 이름이 **중복되면 안 됩니다** | 복구 발생. `구분`, `구분 2` 로 구분하세요 |
| 데이터 행이 **한 줄도 없으면** 표 기능을 적용하지 마세요 | 복구 발생. 머리행만 있으면 일반 셀로 두세요 |
| 표 이름(`displayName`)은 영문·숫자·밑줄만, 공백 없이, 파일 안에서 유일하게 | 복구 발생 |
| 표 범위(`ref`)가 실제 채운 칸과 정확히 같아야 합니다 | 복구 발생 |

원본 표의 머리행이 비어 있거나 겹치면 **고쳐서 넣으세요.** 그대로 옮기는 것보다
읽을 수 있는 이름을 붙이는 편이 낫습니다.

만든 뒤 **파일을 다시 열어 경고가 없는지 확인**하고 결과를 알려주세요.
