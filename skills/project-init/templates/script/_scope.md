## 무엇을 담고 무엇을 뺄 것인가

이 산출물은 **고객사에 송부됩니다.** 원본 문서는 우리 작업용이라 고객이 볼 필요가
없는 것이 섞여 있습니다. 아래를 반드시 걸러내세요.

### 빼야 하는 것

| 대상 | 이유 |
| --- | --- |
| 프론트매터 전체 (`id`, `status`, `template`, `updated` 등) | 내부 관리용 |
| **담당자 이메일·계정** | 개인정보. 이름과 역할만 남깁니다 |
| `## 미결정` 섹션 | 우리 내부의 열린 항목 |
| `## 변경 이력` 섹션 | 내부 작업 이력 |
| `[[문서-id]]` 링크 표기 | 링크는 벗기고 문서 이름만 남깁니다 |
| 추적 ID (`R-01`, `B-01`, `D-001`) | 표의 한 칸을 차지할 뿐 고객에게 뜻이 없습니다. **단, 표 안에서 항목을 가리키는 열이면 남깁니다** |
| 원본 파일명·경로 | 내부 구조 노출 |
| 작성 지침 인용문 | `>` 로 시작하고 "~한다", "~적는다" 로 끝나는 템플릿 안내문. 우리에게 주는 지시이지 내용이 아닙니다 |
| 빈 표·빈 섹션 | 내용이 없으면 그 섹션 자체를 빼세요 |
