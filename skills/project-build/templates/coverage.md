# 구현 커버리지

> **빠뜨린 것과 의도적으로 뺀 것은 다르다.** 그 둘을 구분해 적는 곳이다.
> 3단계는 방향 확인을 위해 화면 1~3개만 만든다. 나머지를 채우는 것이 4단계이므로,
> 무엇이 남았는지 여기서만 보이면 된다.

## 상태 표기

| 표기 | 뜻 |
| --- | --- |
| ✅ | 구현됨 |
| 🟡 | 부분 — 무엇이 빠졌는지 적는다 |
| ⭕ | **의도적으로 뺌** — 근거를 적는다 (예: 콘텐츠 0건 숨김 규칙) |
| ❌ | 미구현 |
