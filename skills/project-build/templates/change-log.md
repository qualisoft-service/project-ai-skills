# 구현 이력

> **4단계 기록이다.** 3단계의 `DS-` 와 구분되는 `BD-` 를 쓴다.

## 기록 규칙

- **화면·기능 단위로** 항목을 추가한다. 몰아서 쓰지 않는다.
- **근거에 수용 기준 ID(`F-01` 등)를 적는다.** 진행률이 이걸 세고,
  한 번도 언급되지 않은 수용 기준은 `build.mjs check` 가 경고한다.
- **대조와 검수 결과를 반드시 적는다.** 비워 두면 "다 봤다"로 읽힌다.
- 통과하지 못한 것은 통과하지 못했다고 적는다.
