# 디자인 질문 은행 (텍스트 설명 방식)

말로만 있는 상태에서 규칙을 뽑아내기 위한 질문. **전부 묻지 않는다.**
한 번에 최대 4문항, 선택형, 모든 문항에 "아직 모름".

---

## A. 인상 — 무엇처럼 보여야 하는가

| 질문 | 선택지 |
| --- | --- |
| 첫인상을 한 단어로 | 신뢰감 / 세련됨 / 친근함 / 대담함 / 차분함 / 전문적 |
| 무게감 | 가볍고 경쾌 / 중간 / 무겁고 진중 |
| 밀도 | 여백이 넓고 성김 / 보통 / 정보가 빽빽 |
| **피하고 싶은 인상** | (자유 입력 — 반드시 받는다) |

> **형용사만 나온 답은 되묻는다.**
> "깔끔하게" → 여백을 넓힌다는 뜻인지, 색을 줄인다는 뜻인지, 요소를 줄인다는 뜻인지.
> 셋은 서로 다른 결과를 만든다.

---

## B. 색

| 질문 | 선택지 |
| --- | --- |
| 밝기 기조 (사이트 전체) | 밝은 배경 / 어두운 배경 / 둘 다 지원 |
| **지배적인 면의 톤** | 첫 화면(Hero)·주요 배너를 **전체와 다르게** 갈 수 있다. 같게 / 반대로 / 아직 모름 |
| 강조색 성격 | 차분한 / 선명한 / 강조색 거의 안 씀 |
| 이미 정해진 색이 있나 | 브랜드 색 있음 / 로고에서 따올 것 / 없음 |
| 색 사용량 | 한 가지 강조색만 / 두세 가지 / 다채롭게 |

> **말로 받지 말고 보여주고 고르게 한다.** `tone-options.html` 로 색만 다른 후보를
> 2~4개 만들어 띄운다. "밝게요"는 흰색인지 옅은 회색인지 알 수 없고,
> 그 차이 때문에 시안을 다시 만든 적이 있다.
> 화면마다 답이 다를 수 있으므로 **화면 단위로** 받는다.

> 2단계 디자인 시스템에 이미 토큰 값이 있으면 **그것을 먼저 보여주고** 유지할지 묻는다.

## C. 타이포그래피

| 질문 | 선택지 |
| --- | --- |
| 제목과 본문의 대비 | 아주 크게 / 보통 / 작게 |
| 글자 인상 | 각지고 또렷 / 부드럽고 둥금 / 중립적 |
| 국문 서체 선호 | 있음 (지정) / 없음 (추천 받음) |
| 본문 크기 | 작게 (14~15) / 보통 (16) / 크게 (17+) |

## D. 레이아웃

| 질문 | 선택지 |
| --- | --- |
| 폭 | 좁고 읽기 중심 / 넓게 꽉 차게 / 콘텐츠마다 다르게 |
| 정렬 | 좌측 정렬 위주 / 중앙 정렬 위주 / 섞어서 |
| 리듬 | 같은 형태 반복 / 섹션마다 변주 |
| 카드 사용 | 적극적으로 / 꼭 필요한 곳만 / 쓰지 않음 |

> 2단계 안티패턴에 "모든 섹션을 카드로" 같은 항목이 있으면 그대로 알린다.

## F. 움직임

| 질문 | 선택지 |
| --- | --- |
| 모션 정도 | 거의 없음 / 은은하게 / 눈에 띄게 |
| 스크롤 등장 효과 | 쓴다 / 안 쓴다 |

> 2단계 인터랙션 문서에 금지 항목(스크롤 하이재킹 등)이 있으면 선택지에서 제외한다.

## G. 참고 대상

| 질문 | 선택지 |
| --- | --- |
| 좋게 본 서비스 | (자유 입력) |
| 그 서비스의 **어느 부분**이 | 색 / 타이포 / 레이아웃 / 여백 / 움직임 / 카피 |
| **싫은** 사례 | (자유 입력) |

> **싫은 사례가 정보량이 더 크다.** 반드시 묻는다.
> "이렇게는 하지 마세요"가 방향을 가장 빨리 좁힌다.

## I. 필수 표기 (웹 · 국내 사업자)

푸터를 그리기 **전에** 받는다. 그리면서 없다는 걸 알면 레이아웃을 다시 짠다.

| 질문 | 선택지 |
| --- | --- |
| 상호 · 대표자명 | (입력) |
| **사업자등록번호** | (입력) — 표기 의무. 가장 자주 빠진다 |
| 주소 | (입력) |
| 연락처 | 메일 / 전화 / 둘 다 |
| 통신판매업 신고 | 대상 / 비대상 / 아직 모름 |
| 개인정보처리방침 · 이용약관 | 있음 / 만들어야 함 / 아직 모름 |
| 채널 링크 | 카카오채널 / 인스타 / 링크드인 / 없음 |

> 없는 값을 지어내지 않는다. `TODO(주체)` 로 자리만 잡고 **리스크 대장에 올린다.**

> 2단계 범위 옵션(`a11y`, `darkmode`)에 이미 답이 있으면 다시 묻지 않는다.
