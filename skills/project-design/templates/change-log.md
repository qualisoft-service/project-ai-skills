# 디자인 수정 이력

> **3단계 기록이다.** 2단계의 의사결정 기록과 별개다.
> 여기에는 *스타일이 어떻게 변해왔는지*가 쌓인다.

## 기록 규칙

- **스타일을 고칠 때마다** 항목을 추가한다. 몰아서 쓰지 않는다.
- 값이 바뀌면 **바뀌기 전 값도 적는다.** 되돌릴 수 있어야 한다.
- "좀 더 밝게" 같은 요청이어도 **결과 값**을 기록한다.
- ID는 `DS-001` 형식. 2단계의 `D-001`·`B-01`과 구분된다.
- **차수**(`Home 7차 시안`)를 시안 파일과 **같은 문자열로** 적는다.
  `build.mjs check` 가 둘을 대조해 어긋나면 경고한다.
- **검수 결과와 "확인 못 함"을 반드시 적는다.** 비워 두면 "다 봤다"로 읽힌다.
  모션·스크롤 동작처럼 도구가 못 보는 것은 늘 있다.

> 파일 자체는 `build.mjs build` 가 `mockups/.history/` 에 자동으로 남긴다.
> 값만 적어서는 되돌릴 수 없다.
