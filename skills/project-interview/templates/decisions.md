# 인터뷰 결정 기록

> **1단계 기록이다.** 2단계의 의사결정 기록과 별개다.
> 여기에는 *기획 단계에서 사람이 말로 정한 것*이 쌓이고,
> 2단계에는 *문서·기술을 만들며 정한 것*이 쌓인다.

## 기록 규칙

- 인터뷰 중 사용자가 **명시적으로 정한 것**만 적는다. 추정은 적지 않는다.
- 되물었을 때 사용자가 기존 판단을 유지했다면 그것도 결정이다. 근거를 함께 남긴다.
- ID는 `DI-001` 형식. 2단계의 `D-001`과 구분된다.
- 날짜별 H2 아래에 항목을 두고, 각 항목의 작성자 속성 표를 채운다.
